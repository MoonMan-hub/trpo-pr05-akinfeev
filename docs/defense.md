# Ответы на контрольные вопросы

1. **Какие входные данные получает приложение и где они находятся?**
   Файлы `data/products.json` и `data/categories.json`, а также GET-параметр `category` из формы фильтра.

2. **Какой участок кода преобразует данные в интерфейс?**
   `CatalogService` превращает JSON в объекты, `public/index.php` выводит объекты в HTML-карточки.

3. **Какое ошибочное состояние проверялось вручную?**
   Неизвестная категория (`?category=999`), пустое название и отрицательная цена в конструкторе `Product`, отсутствие файла данных.

4. **Что изменить при росте проекта?**
   Подключить автозагрузку классов (composer, PSR-4), вынести чтение данных в отдельный репозиторий, добавить контроллер и шаблоны вместо HTML в `index.php`.

5. **Как проверить работу после чистого клонирования?**
   `git clone`, затем `php -S localhost:8000 -t public`, затем пройти `docs/checklist.md`.

6. **Чем серверный PHP отличается от JavaScript в браузере?**
   PHP выполняется на сервере, браузер получает уже готовый HTML. JavaScript выполняется в браузере пользователя.

7. **Когда полезен конструктор?**
   Когда нужно сразу создать объект с корректным состоянием: обязательные значения передаются при создании, а неверные данные отклоняются исключением.

## Как добавить новое свойство в конструктор (для защиты)

Например, `description` у `Product`:

1. В `Product.php` добавить `private string $description;` и параметр `string $description = ''` в конструктор, присвоить `$this->description = trim($description);`.
2. Добавить метод `getDescription()` или `hasDescription()`.
3. В `CatalogService::loadProducts()` передать `$row['description'] ?? ''` в конструктор.
4. В `index.php` вывести `e($product->getDescription())` внутри карточки.
